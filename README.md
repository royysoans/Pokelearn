# Pokelearn 🎮📚

**Pokelearn** is an interactive educational RPG that gamifies learning through the world of Pokémon. Players travel across different regions, battle Gym Leaders, and catch Pokémon by answering educational questions generated by AI.

## 🌟 Features

### 🧠 **AI-Powered Learning**
-   **Dynamic Quizzes**: Powered by **Google Gemini 2.5 Flash**, questions are generated in real-time based on the region and difficulty level.
-   **Adaptive Difficulty**: Questions get harder as you progress from Kanto (Beginner) to Galar (Master).
-   **Multiple Subjects**: Test your knowledge in **Math, Science, and Technical** subjects.

### ⚔️ **Battle System**
-   **Turn-Based Combat**: Classic Pokémon battle mechanics integrated with quiz answers. Answer correctly to attack!
-   **Gym Leaders**: Challenge Gym Leaders in every region to earn badges.
-   **Wild Encounters**: Battle and catch wild Pokémon to expand your team.

### 🌍 **Exploration & Progression**
-   **Region Map**: Unlock and explore 8 different regions (Kanto, Johto, Hoenn, Sinnoh, Unova, Kalos, Alola, Galar).
-   **Pokedex**: Track your collection of caught Pokémon.
-   **Badges**: Earn gym badges to prove your mastery.
-   **Leaderboard**: Compete with other players for the top spot.

### 👤 **Customization & Social**
-   **Trainer Profile**: Customize your trainer's appearance and Trainer Card.
-   **Buddy System**: Choose a buddy Pokémon to accompany you.
-   **Multiplayer (Beta)**: Challenge friends to real-time battles.

## 🛠️ Tech Stack

-   **Frontend**: [React 18](https://react.dev/), [Vite](https://vitejs.dev/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/), [Shadcn UI](https://ui.shadcn.com/), [Framer Motion](https://www.framer.com/motion/)
-   **State Management**: React Context, TanStack Query
-   **Backend & Auth**: [Supabase](https://supabase.com/) (Auth, Database, Edge Functions)
-   **AI**: [Google Gemini API](https://ai.google.dev/) (via Supabase Edge Functions)
-   **Animations**: Framer Motion, Three.js (for 3D elements)

## 🚀 Getting Started

Follow these instructions to set up the project locally.

### Prerequisites
-   Node.js (v18 or higher)
-   npm (v9 or higher) or Bun
-   A Supabase project
-   Google Gemini API Key

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/your-username/pokelearn.git
    cd pokelearn
    ```

2.  **Install dependencies**
    ```bash
    npm install
    # or
    bun install
    ```

3.  **Environment Setup**
    Create a `.env` file in the root directory based on `.env.example` (if available) or add the following keys:
    ```env
    VITE_SUPABASE_URL=your_supabase_url
    VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
    ```
    
    *Note: For the Quiz Generator to work, you must also set `GEMINI_API_KEY` in your Supabase Edge Function secrets.*

4.  **Run the Development Server**
    ```bash
    npm run dev
    ```

    Open [http://localhost:8080](http://localhost:8080) (or the port shown in terminal) to view the app.
